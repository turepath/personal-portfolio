# Python 编程练习

这是一个包含 Python 编程练习、作业和项目的综合集合，适用于学习和课堂使用。本仓库包含 100 多道练习题、期中和期末考试解答以及各种编程项目。

## 📋 仓库结构

### 核心学习材料

- **`Hundred_Problems/`** - 100 道渐进式 Python 编程练习，涵盖从基础概念到中级算法的内容
- **`AllChapter/`** - 按章节划分的练习与解答（第 3-10 章）
- **`Tutoring/`** - 额外的辅导材料和练习题

### 评估与考试

- **`Midterm-66/`, `Midterm-67/`, `Midterm-68/`** - 期中考试解答
- **`Final-66/`** - 期末考试题目
- **`T-Final/`** - 期末考试材料
- **`Test_MidExam 12037/`** - 期中模拟测试

### 项目

- **`Coffee_Shop_System/`** - 咖啡店 POS 系统项目
- **`RegistrationSystem/`** - 学生注册系统
- **`ProgramCalculateGrade/`** - 成绩计算系统
- **`Tcas/`** - 泰国大学入学相关应用
- **`project/`** - 其他各种编程项目

### 补充材料

- **`Brother/`** - 补充练习和实用工具
- **`PyInClass/`** - 课堂 Python 示例
- **`PythonCookbook/`** - Python 代码配方和模式
- **`old_pyinclass/`** - 旧版课堂练习

## 🎯 涵盖主题

- 变量、数据类型和运算符
- 控制流（if/else、循环）
- 函数和模块
- 面向对象编程 (OOP)
- 数据结构（列表、字典、元组）
- 文件 I/O 和异常处理
- 算法和问题解决
- 数据库集成
- Web 应用

## 💻 环境要求

- Python 3.8 或更高版本
- pip（Python 包管理器）
- 虚拟环境（推荐）

## 🚀 快速开始

1. **克隆仓库**

   ```bash
   git clone https://github.com/yourusername/python-programming-exercises.git
   cd python-programming-exercises
   ```

2. **创建虚拟环境**（推荐）

   ```bash
   # Windows
   python -m venv .venv
   .venv\Scripts\activate

   # macOS/Linux
   python -m venv .venv
   source .venv/bin/activate
   ```

3. **安装依赖**（如适用）

   ```bash
   pip install -r requirements.txt
   ```

4. **运行练习**
   ```bash
   python Hundred_Problems/Problem-01.py
   ```

## 📚 如何使用

- **用于学习：** 从 `Hundred_Problems/` 文件夹开始，按顺序完成练习
- **用于参考：** 查看 `AllChapter/` 文件夹，获取按章节组织的结构
- **用于练习：** 查看期中和期末考试文件夹，获取评估类型的题目
- **用于项目：** 探索项目文件夹，获取完整的应用程序示例

## 📝 练习进度

练习按照渐进难度设计：

- 第 1-30 题：基础概念和控制流
- 第 31-60 题：函数、数据结构和算法
- 第 61-100 题：高级主题和基于项目的挑战
