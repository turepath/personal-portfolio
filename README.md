## 项目背景

创业项目微境MicroHabitat，以可组合功能模块提升植物养护装置的扩展性。

## 我的工作

作为联合创始人负责结构设计，规划补光、检测、加湿等可拆模块，参考乐高拼搭方式；完成3D打印打样、多肉种植和部分单片机测试。

## 完成情况

完成原型打样与基础测试；项目获得芙蓉区金种子项目10万元资金支持。

## 技术与工具

SolidWorks；模块化设计；3D打印；原型测试。
