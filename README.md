# 全向轮步兵与串联轮腿结构

[返回个人作品集](https://github.com/turepath/personal-portfolio/tree/main) · [project/rm-infantry分支](https://github.com/turepath/personal-portfolio/tree/project/rm-infantry)

## 项目背景

基于RoboMaster社区开源方案开展学习和结构修改，兼顾机械组建设。

## 我的工作

参与零件库和知识库建设；全向轮方向完成建模、出图、采购、装配及移动/云台/自瞄测试；串联轮腿研究减速箱、髋关节、大小腿轴系与自行车碗组支承。

## 完成情况

全向轮有实物装配和测试；串联轮腿完成设计阶段，未实物装配。

## 技术与工具

SolidWorks；轮组减振；云台；减速箱；髋关节与轴系。
