跟随研发团队在新疆开展棉花打顶机器人测试，围绕刀头汁液黏附固化问题讨论改进。

## 我的工作

参与运输与田地对接、漏打补作业、刀头更换；讨论低成本制刀、快换连接、清洗和表面防黏方案。

## 完成情况

实际参与田间测试与更换刀头；方案讨论不等同于全部改进已实施。模型含企业第一版及现有修改文件。

## 技术与工具
