# 私有作品集访问说明

本作品集应保持为私有仓库，不启用公开 GitHub Pages，也不邀请任何未由本人指定的账号。

`main` 是作品集总览，`project/...` 分支保存各项目。分支用于组织文件，不是访问权限边界；获得仓库访问权的人可以查看所有项目分支。

GitHub 没有“看一次就自动失效”的仓库权限。临时分享可由本人邀请指定 GitHub 账号，结束后撤销，但无法收回对方已经下载的副本。个人账号私有仓库的协作者通常拥有写入权限，不应把邀请理解为只读分享。

如果以后需要只给某人看单个项目，应先把该项目单独放入私有仓库，再授权访问。企业项目和第三方开源材料的分享范围，需要另行确认。
