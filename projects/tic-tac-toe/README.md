# 三子棋视觉机械臂协同系统

视觉组预备阶段的模拟电赛项目，通过识别棋盘和棋子输出机械臂落子坐标。

## 我的工作

使用Python、OpenCV、YOLO及轮廓特征处理图像；完成坐标标定、函数封装，尝试穷举、概率和规则落子策略并加入拦截逻辑。

## 完成情况

本人负责视觉与决策，参与识别、坐标输出和落子联调；源文件中的嵌入式脚本需匹配对应MaxCam硬件固件。
